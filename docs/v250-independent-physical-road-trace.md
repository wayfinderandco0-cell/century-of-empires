# V250 — independent physical road-pixel annotation (ART/PRODUCTION RED)

This isolated iPhone-friendly source-annotation page closes a specific evidence gap: V246 requires an independent **full visible-road trace** and both playable survey indices, but no browser-based original-pixel tool existed for collecting those observations without copying V123 coordinates. The V250 page deliberately hides the V123 target throughout tracing. The user/reviewer loads one **original** 1536×1024 PNG/JPEG/WebP (max 20 MiB), taps the complete visible road, marks playable start/end and exports a SHA256-pinned JSON draft. The tile selector resets the source and trace to avoid WEST/SOUTH cross-contamination. Touch coordinates are mapped back to native source pixels. No original image pixels are altered.

The export has V246's expected keys `sourceSha256`, `fullVisibleRoadPoints`, `playableStartIndex`, `playableEndIndex`, and provenance fields. It intentionally sets `annotationMethod=UNVERIFIED_HUMAN_TRACE_REQUIRES_INDEPENDENT_REVIEW` so **V246 rejects the draft** until a separate human checks the complete physical road, confirms license/creator/source, and explicitly changes the annotation method. This tool does not establish geography, historical cartways, bridge banks, or user art approval.
