# V303 — pinned-source 50-tile prototype
V303 is a separate, testable texture-reuse experiment. It retains 50 octagonal cells, only three distinct photographic sources, one known town (Matrei), and a mathematically connected 57-road-join schematic movement graph. It is **not** 50 individually generated/approved terrains, not true 3D, and not a proven historical road map.
