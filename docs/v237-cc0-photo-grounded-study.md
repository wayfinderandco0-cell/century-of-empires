# V237 — source-proven photographic terrain alternative, NOT APPROVED

Replaces V236 flat vector scenery with **two distinct, SHA1-pinned CC0 Austrian source photographs** (not the rejected V235 lake). WEST: Stijn te Strake, *Forested mountain valley*, Bezau. SOUTH: Paul Gilmore–Pastourmatzis, *Alpine valley*, Brandenberg Alps. Both source pages and CC0 1.0 license URLs are included in the generated manifest; both were posted on Unsplash before its June 2017 licensing change.

The generator uses exactly one native 1536×1024 crop per cell, never a stretched, tiled or cloned image. WEST uses the previously reviewed open meadow region; SOUTH is a new, independent source tested against the exact immutable V123 corridor. The conservative canopy-aware 25px clearance preflight rejects route-over-tree/rock false positives. It writes **actual** source-photo route-review images even if the source fails. Four phone configurations and the unchanged V203 test run only if BOTH necessary ground checks pass; those checks alone never establish human visual acceptance.

The resulting road is the existing V123 gameplay overlay, NOT a historically authenticated road or verified physically baked cartway. It may still look pasted on. The source cameras are not Matrei/V209 registered, bridge banks and onward roads are unverified, and the game art is **not approved**. Any visual shortcomings require a new coherent composition, not procedural noise or an invented geographic registration.

No main, V94 campaign, saves, army sprite, V121/V123 road/bridge, Matrei, or core mechanic changes. No paid services or deployment. Production RED intentionally.
